\subsection{Usuarios}

De igual manera que en la creación de roles, el apartado para crear usuarios se encuentra dentro de \textbf{“Directorio”}.

\begin{figure}[H]
    \centering
    \includegraphics[width=0.8\textwidth]{RolesUsuario/ImgRolesUsuario/S01.png}
    \caption{Apartado de usuarios en Directorio}
\end{figure}

Para crear un nuevo usuario se dará clic en el símbolo de más (+).

\begin{figure}[H]
    \centering
    \includegraphics[width=0.8\textwidth]{RolesUsuario/ImgRolesUsuario/S02.png}
    \caption{Creación de un usuario nuevo}
\end{figure}

Se abrirá un nuevo apartado donde se especificarán los datos del nuevo usuario, como lo es el nombre, email, usuario para ingresar a TIBCO EBX (login) y contraseña.

\begin{figure}[H]
    \centering
    \includegraphics[width=0.8\textwidth]{RolesUsuario/ImgRolesUsuario/S03.png}
    \caption{Registro de datos sobre un usuario nuevo.}
\end{figure}

Una vez llenados todos los apartados necesarios se dará clic en la opción de “Guardar”.

\begin{figure}[H]
    \centering
    \includegraphics[width=0.8\textwidth]{RolesUsuario/ImgRolesUsuario/S04.png}
    \caption{Guardado de usuario nuevo.}
\end{figure}

Una vez guardado el nuevo usuario, en la misma pantalla se habilitará una nueva opción en la cual se podrá asignar un rol al nuevo usuario.

\begin{figure}[H]
    \centering
    \includegraphics[width=0.8\textwidth]{RolesUsuario/ImgRolesUsuario/S05.png}
    \caption{Apartado para asignar roles a un usuario.}
\end{figure}

Para asignar un Rol, en la opción de “Acciones” se selecciona el apartado de “Asociar”.

\begin{figure}[H]
    \centering
    \includegraphics[width=0.8\textwidth]{RolesUsuario/ImgRolesUsuario/S06.png}
    \caption{Asociar rol con usuario}
\end{figure}

Se abrirá una nueva ventana, en la cual se selecciona el Rol que le corresponde al usuario (se puede elegir más de un rol).

Una vez seleccionado(s), se da clic en la opción de “Asociar” para realizar la asignación del Rol.

\begin{figure}[H]
    \centering
    \includegraphics[width=0.8\textwidth]{RolesUsuario/ImgRolesUsuario/S07.png}
    \caption{Asignación de rol.}
\end{figure}

Realizado lo anterior, automáticamente se regresa a la ventana de creación del usuario, donde se podrá visualizar que la asignación del Rol de llevo a cabo.

\begin{figure}[H]
    \centering
    \includegraphics[width=0.8\textwidth]{RolesUsuario/ImgRolesUsuario/S08.png}
    \caption{Rol asignado a un usuario.}
\end{figure}

Bastará con dar clic en “Guardar y Cerrar” para finalizar con la creación del usuario.
