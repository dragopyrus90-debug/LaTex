\section{Requisitos técnicos de TIBCO EBX }

En este manual se describe la instalación y configuración de la plataforma TIBCO EBX 6.1.4 en Windows, usando un servidor web Tomcat 9.0.108 y como DBMS MS Azure SQL Data base. 

La instalación se puede realizar en diferentes servidores web como JBoss EAP, WebSphere, WebLogic y se pueden utilizar diferentes DBMS como Oracle Data Base, PostgreSQL, Amazon Aurora PostgreSQL, SAP HANA Data Base, Microsoft Azure SQL Data Base y H2. Para ver más información sobre la instalación de estos componentes consultar el archivo TIB\_ebx\_6.1.4\_installation.pdf localizado en el instalador de TIBCO EBX en la ruta /EBX/6.1.4/. 

Versiones de servidores de aplicaciones soportadas: 
\begin{itemize}
  \item JBoss EAP 6.0 o superior. 
  \item WebLogic 14c o superior
  \item WebSphere Application Server 8.5.5 o superior. 
  \item Tomcat 7.0 a 10.0 
\end{itemize}

\begin{quote}
  \textbf{Nota:} El aplicativo y versión instalados para CMI serán sobre el servidor Tomcat 9.0 o superior.
\end{quote}

Versiones de bases de datos soportadas: 
\begin{itemize}
    \item Oracle Data Base 12c o superior. 
    \item Postgres SQL 9.6 o superior. 
    \item Amazon Aurora PostgreSQL 2.3 (compatible con PostgreSQL 10.7) o superior. 
    \item SAP HANA Data Base 2.0 o superior. 
    \item Microsoft Azure SQL Data Base v12. 
    \item H2 v1.4.196 o superior. 

\end{itemize}
